# 2026-11-11 — Première source étudiée : le SDLC à 11 phases de SFEIR

## Ce qu'on a fait

Première application de la [politique d'inspiration](../licences.md) sur une source réelle : l'article de SFEIR « Un SDLC piloté par l'IA : le cycle SFEIR à 11 phases ».

1. **Vérifier la licence avant tout.** L'article est « tous droits réservés » : on se limite donc au niveau « idée ». On ne copie ni texte, ni tableau, ni schéma ; la synthèse est rédigée avec nos propres mots.
2. **Rédiger une note d'analyse** ([docs/inspirations/sfeir-sdlc-ai.md](../inspirations/sfeir-sdlc-ai.md)) : synthèse, idées retenues, idées écartées.
3. **Créditer** la source dans [CREDITS.md](../../CREDITS.md) et ajouter les sources qu'elle cite à la liste « à étudier ».
4. **Intégrer dans la [vision](../vision.md)** trois idées validées :
   - le principe de **discipline de la preuve** ;
   - la phase de **dépréciation** ;
   - une section **domaine d'application**.

## Ce qu'on a appris

- **Une source fermée reste exploitable.** « Tous droits réservés » n'empêche pas de s'inspirer : ça oblige seulement à reformuler et à créditer.
- **Garder le recul sur les chiffres.** Les gains annoncés par un acteur commercial ne servent pas d'arguments ; seules les idées sont évaluées.
- **Penser solo, pas équipe.** Un cycle conçu pour des équipes se transpose en gardant les *responsabilités* sans les *rôles*.
